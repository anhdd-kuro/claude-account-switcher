# TokenTracker UI adaptation

The native limits layout, progress-bar presentation and provider logo assets
are adapted from TokenTracker by xiufengsun, commit
56e21b4abc981896b85c906b6105b58dc3a520ba.

Source: https://github.com/xiufengsun/TokenTracker

Referenced native source:
- TokenTrackerBar/TokenTrackerBar/Views/UsageLimitsView.swift
- TokenTrackerBar/TokenTrackerBar/Views/UsageLimitBar.swift
- TokenTrackerBar/TokenTrackerBar/Utilities/Colors.swift
- TokenTrackerBar/TokenTrackerBar/Services/StatusBarController.swift
- TokenTrackerBar/TokenTrackerBar/Assets.xcassets/ClaudeLogo.imageset/claude-code.svg
- TokenTrackerBar/TokenTrackerBar/Assets.xcassets/CodexLogo.imageset/codex.svg

Adaptations use AppKit menu items/views in Python, native semantic colors,
profile-specific limits, and the existing account-switching controls.
