# Native menu design

The reference is TokenTracker's limits panel. UI/UX Pro Max guidance is applied to hierarchy, consistent spacing, contrast, and accessible status. The app stays in AppKit: system fonts and semantic colors replace web font and palette recommendations.

- One 440-point minimum content width, with 20-point side insets.
- Provider headings use a 16-point brand mark and system semibold text in a 36-point row.
- Native clickable profile rows retain keyboard navigation, hover, and selection checkmarks. Organization and plan identify Claude profiles; email is available in a tooltip. Duplicate labels include email.
- Usage windows share label, bar, percentage, and reset columns. Rows have a 20-point pitch, with consistent outer spacing.
- Active profiles use native checkmarks only; no persistent tinted backgrounds.
- System label colors adapt to light/dark appearance. Percentages accompany colored bars so color is not the only indicator.
- Missing reset timestamps omit the reset value without hiding valid usage. Provider summaries use the active profile's remaining usage.
- Settings and account-management actions remain ordinary native menu items.
